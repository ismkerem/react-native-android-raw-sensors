# react-native-android-raw-sensors

High-frequency, uncalibrated raw sensor access for React Native Android using TurboModules. Access accelerometer bias and nanosecond timestamps for physics and research applications.

## Installation


```sh
npm install react-native-android-raw-sensors
```


## Usage


```js
import { multiply } from 'react-native-android-raw-sensors';

// ...

const result = multiply(3, 7);
```
